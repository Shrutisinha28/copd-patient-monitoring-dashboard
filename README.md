# COPD Patient Monitoring Dashboard

An interactive Power BI dashboard designed to monitor COPD patient symptoms, identify risk patterns, and support data-driven healthcare insights.

---

## Project Overview

Chronic Obstructive Pulmonary Disease (COPD) requires continuous monitoring of symptoms and external factors such as environmental conditions.

This project focuses on building a patient-centric dashboard that enables:
- Tracking of symptom severity over time
- Identification of high-risk patterns
- Integration of contextual data like weather and air quality
- Improved decision-making for both patients and healthcare providers

---

## Objectives

- Visualise daily symptom trends (breathlessness, cough, wheeze)
- Highlight severity levels using conditional formatting
- Analyse exacerbation frequency by trigger and time (monthly trends)
- Provide contextual insights using weather and location data
- Create an intuitive and user-friendly dashboard experience

---

## Key Features

- **Symptom Tracking:** Interactive charts to monitor breathlessness, cough, and wheeze over time  
- **Conditional Formatting:** Severity levels highlighted using colour-coded thresholds  
- **Dynamic Analysis:** Toggle between trigger-based and month-based insights using bookmarks  
- **Weather Integration:** Air quality, temperature, and humidity included for contextual analysis  
- **GP Practice Details:** Contact and location information integrated into the dashboard  
- **Navigation System:** Multi-page layout with buttons and drill-through functionality  
- **User-Centric Design:** Clean layout with accessibility considerations (e.g., colour-blind friendly colour choices)

---

## Tools & Technologies

- Power BI  
- DAX (Data Analysis Expressions)  
- Data Modelling  
- Data Visualisation  

---

## Dataset

The dataset includes:
- Patient symptom records (Date, Breathlessness, Cough, Wheezing)
- Exacerbation details (Triggers, Duration)
- Weather data (Temperature, Air Quality, Humidity)
- GP Practice information (Name, Contact, Location)

*(Note: This project uses synthetic/sample data for demonstration purposes.)*

---

## How to Use

1. Download the `.pbix` file from this repository  
2. Open in Power BI Desktop  
3. Interact with the dashboard:
   - Use filters and slicers  
   - Switch between views (Trigger / Month)  
   - Explore symptom trends and insights
